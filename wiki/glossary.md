# 名詞小辭典

> 逐頁稿中，術語第一次出現的那一頁，必須在「術語」欄寫出這裡的白話解釋（`scripts/check.py G4` 會自動檢查）。
> 解釋內容都來自右欄的 Wiki 頁面，不另外新增事實。新增術語時，依長度由長到短排列不影響檢查。

| 術語 | 白話解釋 | 詳見 |
|---|---|---|
| 通膨 | 物價持續上漲，同樣的錢能買的東西變少 | [通貨膨脹](concepts/inflation.md) |
| 購買力 | 一筆錢能買到多少東西 | [通貨膨脹](concepts/inflation.md) |
| 複利 | 把賺到的報酬再放回本金，下一期用更大的本金繼續滾 | [複利](concepts/compound-interest.md) |
| 報酬率 | 賺的錢占本金的比例 | [複利](concepts/compound-interest.md) |
| 緊急預備金 | 只在意外時才動用的一筆錢 | [緊急預備金](concepts/emergency-fund.md) |
| 循環利息 | 信用卡沒繳清，剩下的錢被收的利息 | [先理債再理財](concepts/debt-first.md) |
| 風險屬性 | 你能承受資產上上下下到什麼程度 | [風險屬性](concepts/risk-tolerance.md) |
| 昨收 | 前一個交易日的收盤價，用來算今天的漲跌 | [看懂報價畫面](concepts/quote-screen.md) |
| 成交量 | 一段時間內成交的總數量，台股個股多以「張」計 | [看懂報價畫面](concepts/quote-screen.md) |
| 紅 K | 收盤價比開盤價高的 K 線 | [K 線](concepts/k-line.md) |
| 綠 K | 收盤價比開盤價低的 K 線 | [K 線](concepts/k-line.md) |
| 五檔 | 看盤畫面上還在排隊、沒成交的買單和賣單，各列最好的五個價格 | [五檔報價](concepts/order-book.md) |
| 委買 | 想買的人出的價格和張數 | [五檔報價](concepts/order-book.md) |
| 委賣 | 想賣的人開的價格和張數 | [五檔報價](concepts/order-book.md) |
| 對手方 | 跟你交易的另一邊：你要買，對手方就是賣方 | [五檔報價](concepts/order-book.md) |
| 大盤 | 發行量加權股價指數，代表上市股票整體的漲跌 | [大盤](concepts/market-index.md) |
| ETF | 在交易所像股票一樣買賣的基金，報酬跟著它追蹤的指數走 | [大盤](concepts/market-index.md) |
| 市場情緒 | 投資人整體的樂觀或恐慌，會讓很多股票一起漲跌 | [大盤](concepts/market-index.md) |
| 股本 | 公司發行的股票規模；股本越大，對大盤影響越大 | [大盤](concepts/market-index.md) |
| 漲停 | 一天內漲到上限（開盤競價基準＋10%） | [漲跌幅限制](rules/price-limit.md) |
| 跌停 | 一天內跌到下限（開盤競價基準－10%） | [漲跌幅限制](rules/price-limit.md) |
| 零股 | 1～999 股的交易，不到一張 | [整股與零股](rules/trading-unit.md) |
| 盤後零股 | 收盤後 13:40～14:30 另外進行的零股交易 | [台股交易時間](rules/trading-hours.md) |
| 限價 | 自己指定價格下單 | [委託種類](rules/order-types.md) |
| 市價 | 不指定價格，直接跟對手方正在排隊的價格成交 | [委託種類](rules/order-types.md) |
| ROD | 當日有效：今天收盤前都有效，沒成交就繼續排隊 | [委託種類](rules/order-types.md) |
| IOC | 立即成交否則取消：能成交多少算多少，剩下的取消 | [委託種類](rules/order-types.md) |
| FOK | 全部成交否則取消：不能一次全部成交就整筆取消 | [委託種類](rules/order-types.md) |
| 手續費 | 付給券商的費用，買和賣各收一次 | [交易成本](rules/trading-costs.md) |
| 證交稅 | 賣出股票時繳給政府的稅 | [交易成本](rules/trading-costs.md) |
| 營業日 | 股市有開的日子，週末和休市日不算 | [T+2 交割](rules/settlement-t2.md) |
| 委託單 | 你送給券商的買賣指令：買或賣、價格、數量、等多久 | [委託種類](rules/order-types.md) |
| 交割帳戶 | 開戶時綁定、用來扣款和入帳的銀行帳戶 | [T+2 交割](rules/settlement-t2.md) |
| 違約交割 | 買了股票卻沒在期限內付錢 | [違約交割](concepts/default-settlement.md) |
| 聯徵 | 銀行會查詢的個人信用紀錄 | [違約交割](concepts/default-settlement.md) |
